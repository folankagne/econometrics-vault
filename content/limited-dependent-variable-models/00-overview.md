title: Limited Dependent Variable Models — Overview

Neither course develops dedicated models for outcomes with restricted ranges: binary indicators beyond the [linear probability model](../ols-estimation/00-overview.md) already covered from Econ 1, corner-solution variables (spending that piles up at zero), count data, or the formal machinery behind the [sample-selection correction](../treatment-effects/experimental-selection-correction-estimator.md) used informally elsewhere in this vault. This folder fills that gap entirely from Wooldridge (2016), Ch.17, and every entry is tagged `beyond-lectures`.

## Reading order

1. [Logit and Probit Models for Binary Response](logit-and-probit-models.md)
2. [Partial Effects in Nonlinear Response Models](partial-effects-in-nonlinear-response-models.md)
3. [The Tobit Model for Corner Solution Responses](the-tobit-model-for-corner-solutions.md)
4. [The Poisson Regression Model for Count Data](poisson-regression-for-count-data.md)
5. [Sample Selection and the Heckit Method](sample-selection-and-the-heckit-method.md)

See also: [the linear probability model](../ols-estimation/00-overview.md) (Econ 1) for the baseline this folder improves on, and [the experimental selection correction estimator](../treatment-effects/experimental-selection-correction-estimator.md) (Econ 2b), which is a modern relative of the classical Heckit approach developed here.
